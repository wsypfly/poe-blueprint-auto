==============================
蓝图自动确认工具 v4 - 使用说明
==============================

【功能说明】
自动处理流放之路蓝图，批量确认蓝图中的小格子和人物卡片。

【支持分辨率】
支持任意分辨率，自动适配。蓝图界面必须在屏幕内完整显示。

【使用前准备】
1. 安装 Python 3.8+
2. 安装依赖：pip install -r requirements.txt
3. 打开游戏，进入计划桌界面
4. 将蓝图放入背包（列优先：1-4-7-10, 2-5-8-11...）
5. 在蓝图界面，将视角拉到最大（滚轮拉满）

【启动方法】
普通模式：
  python run_blueprint_auto.py

调试模式（保存截图到debug目录）：
  python run_blueprint_auto.py --debug

【操作说明】
- F2: 开始运行
- F3 / ESC: 停止运行

【运行流程】
1. 扫描背包，识别非空格子
2. 依次处理每个蓝图：
   a. Ctrl+C 检查格子是否为蓝图
   b. Ctrl+左键 放入蓝图
   c. 识别蓝图小格子，依次点击
   d. 点击小格子后，识别并点击人物卡片
   e. 所有小格子处理完后，点击确认按钮
   f. Ctrl+左键 取回蓝图到背包
3. 重复直到所有蓝图处理完成

【注意事项】
- 游戏窗口必须在前台
- 蓝图视角必须拉到最大
- 背包中的蓝图按列优先顺序处理
- 如果检测失败，程序会自动停止

【调试方法】
1. 使用 --debug 参数启动，截图保存到 debug 目录
2. 查看日志文件：logs/run_blueprint.log

【常见问题】
Q: 为什么检测不到小格子？
A: 确保蓝图视角拉到最大，界面完整显示在屏幕内。

Q: 为什么点击没有生效？
A: 确保游戏窗口在前台，不要有其他窗口遮挡，脚本需管理员运行

Q: 如何停止程序？
A: 按 F3 或 ESC 键。
